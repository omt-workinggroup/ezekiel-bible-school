# Ezekiel Bible Institute

Marketing site for Ezekiel Bible Institute. Static HTML, CSS and a little JavaScript; no build step.

## Local development

```sh
npx serve .
# or
python3 -m http.server 8000
```

## Structure

| Path | Page |
| --- | --- |
| `index.html` | Home |
| `programmes.html` | Programmes, entry requirements, online study |
| `about.html` | History, teaching approach, faculty |
| `admissions.html` | How to apply, key dates, fees, FAQ |
| `visit.html` | Events, location, office hours |
| `enquire.html` | Prospectus request form |
| `404.html` | Not found |

`styles.css` holds all styles (mobile first) and `main.js` handles the mobile menu,
programme filter and enquiry form. `vercel.json` turns on clean URLs, so
`/programmes` serves `programmes.html`.

The pages are generated by `scripts/build.py`, which holds the shared header,
footer and page content. Edit it, then rebuild:

```sh
python3 scripts/build.py .
```

### Hero photos

Put photos in `img/` (about 2400px wide, under 400 KB each, ideally `.webp`) and
list them in `HERO_IMAGES` near the top of `scripts/build.py`. With more than one
photo the hero crossfades between them every seven seconds. With none, it shows
the plain navy background.

### Icons

`favicon.svg` and `favicon.ico` for browser tabs, `apple-touch-icon.png` for iOS,
`icon-192.png`, `icon-512.png` and `icon-maskable-512.png` for Android (listed in
`site.webmanifest`), and `og-image.jpg` for link previews. `logo.svg` is the
full-colour logo for print.

## Deployment

Hosted on Vercel. Every push to `main` deploys to production; other branches get preview URLs.
